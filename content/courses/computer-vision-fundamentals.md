# Computer Vision Fundamentals

Computer vision enables machines to interpret and understand visual information from the world. This course takes you from image processing basics through CNNs to transfer learning with pre-trained models.

## Learning Outcomes

- Understand digital image representation and processing fundamentals
- Apply image transformations and filtering with OpenCV
- Understand CNN architectures and convolution operations
- Implement image classification using transfer learning with pre-trained models

## Prerequisites

- Python for Data Science course (or equivalent)
- Deep Learning & Neural Networks course
- Linear algebra basics (matrices, convolutions)
- Familiarity with PyTorch or TensorFlow

## Course Structure

### Section 1: Image Processing Fundamentals
Understand digital images, color spaces, and basic image operations using OpenCV.

### Section 2: Deep Learning for Vision
CNN architectures and convolution operations, then transfer learning with pre-trained models.

More sections — object detection, image segmentation, and advanced topics — are in development and will be added as they are finished.

## Why Learn Computer Vision?

**Diverse Applications**: Self-driving cars, medical imaging, robotics, AR/VR

**Foundation for Multimodal AI**: Understanding images is crucial for modern AI systems

**Tangible Impact**: Build systems that can "see" and understand the world

## Time Commitment

- **Total Duration**: ~4 hours of lessons
- **Format**: Self-paced

## Tools You'll Use

**Python** (v3.10+): Primary programming language
**OpenCV**: Computer vision library
**PyTorch**: Deep learning framework
