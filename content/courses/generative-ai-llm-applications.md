# Generative AI & LLM Applications

Large Language Models are revolutionizing software development. This course covers how LLMs actually work, how to prompt them reliably, and how to ground them in your own data with RAG.

## Learning Outcomes

- Understand how LLMs work and their capabilities/limitations
- Master prompt engineering for reliable results
- Implement Retrieval Augmented Generation (RAG) systems

## Prerequisites

- Python programming skills
- Basic understanding of APIs and HTTP requests
- Familiarity with JSON data format
- No machine learning background required (helpful but not necessary)

## Course Structure

### Section 1: Understanding LLMs and Prompt Engineering
How LLMs work, capabilities, limitations, and techniques for getting reliable, high-quality outputs.

### Section 2: Retrieval Augmented Generation (RAG)
Build systems that combine LLMs with your own data.

More sections — LLM APIs in depth, agents and tool use, and production deployment — are in development and will be added as they are finished.

## Why Learn LLM Application Development?

**Transformative Technology**: LLMs are changing every industry

**Rapid Innovation**: New capabilities released monthly

**Accessible**: Build powerful apps without ML expertise

## Time Commitment

- **Total Duration**: ~3 hours of lessons
- **Format**: Self-paced

## Tools You'll Use

**Python** (v3.10+): Programming language
**LLM APIs**: OpenAI, Anthropic Claude, and open-source models
**Vector stores**: For RAG retrieval
