# SQL for Data Analysis

SQL (Structured Query Language) is the language of data. Every data role requires SQL proficiency. This course covers the core query toolkit: retrieving, aggregating, joining, and analyzing data.

## Learning Outcomes

- Write SQL queries to retrieve and filter data
- Use aggregations to summarize data (COUNT, SUM, AVG, GROUP BY, HAVING)
- Combine data from multiple tables with JOINs
- Use window functions for rankings, running totals, and LAG/LEAD

## Prerequisites

- Basic computer skills
- Understanding of spreadsheets (Excel, Google Sheets)
- No prior programming experience needed
- Interest in working with data

## Course Structure

### Section 1: SQL Fundamentals
SELECT statements, filtering with WHERE, sorting, and aggregation with GROUP BY and HAVING.

### Section 2: Joining Tables
INNER JOIN, LEFT JOIN, RIGHT JOIN, and combining data across tables.

### Section 3: Advanced Queries
Window functions: ROW_NUMBER, RANK, running totals, and LAG/LEAD.

More sections — subqueries and CTEs, plus real-world analytics projects — are in development and will be added as they are finished.

## Why SQL for Data Analysis?

**Universal Skill**: Used in every company with data

**Immediate Impact**: Query databases directly for instant insights

**Portable**: Works across PostgreSQL, MySQL, SQLite, BigQuery, Snowflake
