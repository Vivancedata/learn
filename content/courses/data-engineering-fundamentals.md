# Data Engineering Fundamentals

Data engineering is the foundation that makes data science possible. This course introduces the concepts behind reliable data pipelines and gets you building scheduled workflows with Apache Airflow.

## Learning Outcomes

- Understand data engineering principles and the modern data stack
- Compare ETL and ELT patterns and know when to use each
- Reason about data quality dimensions and validation
- Distinguish batch from streaming processing
- Build and schedule data pipelines with Apache Airflow

## Prerequisites

- Python for Data Science course
- SQL Data Analysis course
- Basic understanding of databases
- Command line proficiency

## Course Structure

### Section 1: Data Engineering Fundamentals
Understand the role of data engineering, the modern data stack, pipeline basics, ETL vs ELT, and data quality.

### Section 2: Workflow Orchestration
Build and schedule data pipelines with Apache Airflow.

More sections — data modeling, warehousing, Spark, and dbt — are in development and will be added as they are finished.

## Why Learn Data Engineering?

**Critical Role**: Every data-driven organization needs data engineers

**Foundation for ML**: Quality data is essential for successful ML projects

**Career Growth**: Clear path to senior engineer, architect, and leadership roles

- **Total Duration**: ~2 hours of lessons
- **Format**: Self-paced

**Python** (v3.10+): Primary programming language
